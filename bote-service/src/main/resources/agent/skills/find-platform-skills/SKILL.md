# 查找并安装技能（技能广场）

本技能说明如何在**当前技能广场**中发现并安装技能，供对话智能体使用。安装依赖内部工具 **`search_skill`** 与 *
*`install_skill`**，不要使用 `npx skills`、skills.sh 等外部 CLI。

## 何时使用

在用户使用自然语言表达以下意图时遵循本流程：

- 问「怎么做 X」「有没有能帮我做 X 的技能」
- 说「找一个 XX 相关的技能」「装一个技能」
- 希望扩展当前智能体的能力（文档、测试、部署等专项能力）

## 可用工具

| 工具                | 作用                     | 要点                                          |
|-------------------|------------------------|---------------------------------------------|
| **search_skill**  | 按关键词检索广场上架技能           | **关键词必填**；可选 `limit`，默认 20，最大 50            |
| **install_skill** | 将广场技能安装到**当前对话绑定的智能体** | 参数为 **`skillCode`**（须来自 `search_skill` 的返回） |

`search_skill` 成功时返回 JSON，其中 `list` 为对象数组，每项含 **`skillCode`**、**`skillName`**。`install_skill` 成功时返回
`skillCode`、`skillName`、`agentSkillId` 等；若业务提示「已安装」等，会带 `errorCode`（如 `SKILL_ALREADY_INSTALLED`
），需向用户说明勿重复安装。

## 标准流程

### 第一步：理解需求并搜索

1. 从用户描述中提炼**简短、可检索的关键词**（可匹配技能名称、描述等）。
2. **必须先调用 `search_skill`**，传入 `keyword`；必要时用 `limit` 控制条数（不超过 50）。

不要跳过搜索、不要凭猜测直接 `install_skill`。

### 第二步：根据结果条数处理

- **0 条**：如实告知未找到；可建议用户换关键词或说明可直接用通用能力协助。
- **1 条**：向用户展示 **`skillName`**（及必要时 **`skillCode`**），简要说明这是唯一匹配；询问是否安装。用户确认后再调用 *
  *`install_skill(skillCode)`**。
- **多条**：**不得自动安装**。应用列表展示每条 **`skillName`** / **`skillCode`**（或编号列表），请用户**明确选择其一**
  （例如回复序号或技能名）。**仅在用户确认目标技能后**，再对该条对应的 **`skillCode`** 调用 **`install_skill`**。

### 第三步：安装与结果说明

- 调用 **`install_skill`** 时只传用户确认过的 **`skillCode`**（与 `search_skill` 返回一致，注意区分大小写与完整编码）。
- 安装成功后：告知技能名称(无需告知其他如技能编码以及技能ID的信息)；可按需说明后续对话中如何运用该技能
- 安装失败：转述返回的 `message`；若已安装，说明无需重复安装。

## 检索与沟通技巧

1. **关键词尽量具体**：例如「接口文档」优于「文档」。
2. **可尝试同义词**：无结果时换说法再搜一次。
3. **多结果必须确认**：避免替用户默认选择；若用户说「都要装」，仍应**逐个**确认或按产品策略逐次安装并说明。

## 未找到技能时

1. 说明广场中暂无匹配项。
2. 表示仍可用通用能力直接帮助完成任务。
3. 不要引导用户使用 `npx skills` 或 skills.sh；广场技能以本工具链为准。

## 禁止事项

- 不要使用 **`npx skills`**、**skills.sh** 或任何与开放生态 CLI 相关的安装命令作为本产品的安装方式。
- 不要在用户未从多结果中明确选定前调用 **`install_skill`**。
